# PF_Project-Quiz-MCQ-
I made MCQ quiz system in C 
This project includes quizzes from three different subjects:
Mathematics
Programming Fundamentals
Ideology of Pakistan
Features
Interactive multiple-choice questions (MCQs).
Three different subject categories.
score calculation.
Negative marking for incorrect answers.
Final score out of 5.
Grade calculated on the total score (A, B, C, F).
Displays the final quiz result.
